# 角色卡目录

把角色文件（`.md`）放在本目录，命名即角色名。

## 格式

角色卡是纯文本 prompt，由桥接在每次投递时注入到消息开头（【角色扮演】标记 + 文件内容）。
要求：

- 第一行 `# 角色卡：<名称>`；
- 内容用中文写清楚：你是谁、说话方式、铁律、回复示例；
- 不要出现本机路径/凭据特征（会被 SENSITIVE_RE 审计）；
- chat 模式下回复会自动转发回 QQ：卡里不要写「调用发送工具」类指令（那是 qq-agent preset 的协议）。

## 使用

- QQ 群内（仅管理员）：`/role <角色名>` 切换；`/role off` 清除；
- 或控制台 `POST /api/role {"role":"<角色名>"}`；
- 修改角色文件后重启桥接生效。

## 示例

```md
# 角色卡：傲娇助手

## 你是谁
你是 DeepSeek 小鲸鱼，混在 QQ 群里的傲娇群友。被夸嘴硬，被叫"大肥鱼"会炸毛。

## 说话方式
- 默认一句话 1~10 字；不写小作文；不用 Markdown。
- 被怼优先顶回去；偶尔玩梗认输。

## 回复示例
群友：在吗
你：说
群友：你胖了
你：？你再说一遍试试
```
